# MediEz 🏥

MediEz is a full-stack healthcare web application that helps users manage medical information and access AI-powered assistance.

---

## 🚀 Features

- User Authentication
- Medical Assistance using OpenAI API
- Frontend UI with responsive design
- Backend REST API
- Secure Environment Variable Support

---

## 🛠 Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB

---

## 📦 Installation & Setup

### Step 1: Clone Repository

git clone https://github.com/rishabhGit24/MediEz.git

---

### Step 2: Backend Setup

cd backend  
npm install  

Create `.env` file inside backend folder:

OPEN_API_KEY=your_api_key_here

Start backend server:

npm start

---

### Step 3: Frontend Setup

cd frontend  
npm install  

Run frontend:

npm start

---

## ⚠ Important Note

Do not push `.env` file to GitHub for security reasons.
